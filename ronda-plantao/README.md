# Agente local do plantão

Agente do Agent SDK para o plantão defensivo da Ronda. A forma de rodar, as variáveis e o limite do VulDB estão no README da raiz, na seção "Agente local no Cursor".

Na raiz do repositório:

```bash
npx --yes "@grok/agent-sdk@0.7.2" dev ./ronda-plantao
```

O playground abre em http://127.0.0.1:3000/playground.
